# 32-Team R32 Knockout Bracket Support

Added proper first-round (`r32`) support to the knockout generator and progression engine so a 32-club competition can be created. Required by the Nedbank Cup in `.opencode/context/two-divisions/season-4-two-division-setup_2026-09-27.md`, and builds on the existing knockout work in this category (`.opencode/context/knockout-generation/knockout-autogen-removal_2026-08-23.md`, `.opencode/context/knockout-generation/knockout-daily-cap_2026-08-23.md`).

## Problem

`lib/tournament-progression.ts` only knew how to build brackets of 4, 8 or 16 teams. A 32-team competition had no representable first round:

- `KnockoutRound` had no `r32` member, so there was no way to express the round in the database or the UI.
- `BRACKET_PROGRESSION` had no matchday band for it, so R32 winners could not be advanced into R16.
- `generateTBCKnockouts()` would have produced a bogus 16-team bracket instead of a real 32-team one.
- Eight call sites each carried their own hardcoded knockout-round list, so adding a round meant editing all of them.

## Fix

### Schema
- `supabase/migrations/077_add_r32_round_type.sql`: adds `r32` to `fixtures_round_type_check`. Applied and the constraint verified.

### Progression engine (`lib/tournament-progression.ts`)
- `KnockoutRound` gains `'r32'`.
- `BRACKET_PROGRESSION` gains a new 32-team band: R32 matchdays **401–416** advance into the existing R16 band 51–58.
- `ROUND_STAGE_OFFSET` gives `r32` an offset of `-1` so it dates one stage before R16.
- A 32-team bracket is **single-leg only**; requesting two legs returns `A 32-team bracket is single-leg only (R32 has no leg-2 band)` instead of generating a broken bracket.
- `assignKnockoutDates()` anchors a tournament that has no group stage to its own `settings.start_date` rather than `today`. Without this, a straight knockout (the Nedbank Cup) got dated from the day the script ran instead of after the leagues.
- **Sibling-lookup bug fixed.** `advanceWinner()` located a tie's other leg with `matchday ± 10` alone. That is unsafe now that R32 occupies 401–416: an R32 tie at matchday 401 would have found matchday 411 — which is *another R32 tie* — and wrongly tried to aggregate two unrelated matches. The lookup now also filters on `round_type` and the opposite `leg`, so a single-leg round can never pick up an unrelated tie in its `+10` range.
- `lib/tournament-rounds.ts` (new): exports `KO_ROUNDS` and round labels, and the eight hardcoded round arrays (cron, webhook, finalise-result, admin tournament pages) now import it.
- `lib/supabase/types.ts` and `lib/fixture-generator.ts`: `r32` added to the round unions.
- Labels for R32 added to admin fixture management (desktop + mobile) and the news data builder; `lib/og.ts` already understood `r32`.

### Super Cup interaction
- `checkAndCreateSuperCup()` now prefers `settings.is_continental` when picking the two continental competitions and reads `settings.super_cup_name`, so it can no longer select the Nedbank Cup. The generated fixture uses `round_type: 'super_cup'` so final-award handling does not recurse into itself. See `.opencode/context/knockout-generation/auto-super-cup-generation_2026-08-25.md` and `.opencode/context/knockout-generation/super-cup-bugfix_2026-08-26.md`.
- A pre-created Super Cup **shell** is now adopted rather than skipped: if its only fixture is still a TBC placeholder, the CAF winners are written into that placeholder in place; once real teams are set, the Super Cup is settled.

## Verification
- `npx tsc --noEmit` clean after each stage.
- Season 4's Nedbank Cup generated 31 fixtures: 16 R32 + 8 R16 + 4 QF + 2 SF + 1 final, with all 32 clubs appearing exactly once across the R32.
- 0 cases of any club being double-booked on a date across the whole season.

## Next steps / notes
- CAF knockout brackets are still generated after the group stage via the admin *Generate Knockouts* action, which bails out if knockout fixtures already exist. That is why Season 4 has 608 fixtures now and reaches 634 later — deliberate, see `.opencode/context/two-divisions/season-4-two-division-setup_2026-09-27.md`.
- Matchday 401–416 is now a reserved band. Any future single-leg round added in that range would reintroduce the sibling-lookup collision, so keep the `round_type` + `leg` filters in `advanceWinner()`.
