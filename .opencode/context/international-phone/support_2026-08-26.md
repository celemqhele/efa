# International Phone Number Support

**Date:** 2026-08-26

## Problem
Phone number functions in the WhatsApp webhook were hardcoded for South African (+27) numbers only. Users with international numbers (e.g., +389 North Macedonia) experienced issues during onboarding and contact card generation.

The `toInternationalPhone` function prepended `27` to ANY `0`-prefixed number, and `phoneNumbersMatch` only handled SA local↔international conversion.

## What was fixed

### `toInternationalPhone` (webhook/route.ts)
- **Before:** Any number starting with `0` got `27` prepended (SA-only)
- **After:** Only prepends `27` if the number is exactly 10 digits starting with `0` (SA local format). Other international numbers pass through unchanged.

### `phoneNumbersMatch` (webhook/route.ts)
- **Before:** Only matched SA local (`0694021679`) ↔ international (`27694021679`)
- **After:** Also matches generic local format (starts with `0`) against any international country code (e.g., `071670793` ↔ `38971670793`)

### Profile page placeholders
- Updated from `+27 12 345 6789` to `+1 234 567 8901` on both desktop and mobile profile pages to indicate international support.

## Files modified
- `app/api/webhook/route.ts` — `toInternationalPhone` and `phoneNumbersMatch` functions
- `app/(protected)/profile/_desktop.tsx` — phone input placeholder
- `app/(protected)/profile/_mobile.tsx` — phone input placeholder

## What did NOT need changing
- Onboarding flow — WhatsApp `from` numbers are already stored in international format
- Login — Uses email, not phone
- `wa.me` links — Already use raw digits, works for any country
- Admin set-whatsapp — Strips non-digits, works for any number
