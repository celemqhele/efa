5. HOW TO IMPLEMENT MULTIPLE THEMES
=============================================================================

You only need to change the 12 CSS custom properties in app/tokens.css.
Wrap each theme in a data-attribute selector:

  /* tokens.css */
  :root, [data-theme="dark"] {
    --color-bg-base: #0F1117;
    --color-bg-surface: #171A21;
    --color-accent: #D6B65D;
    ...
  }

  [data-theme="light"] {
    --color-bg-base: #F8F9FA;
    --color-bg-surface: #FFFFFF;
    --color-bg-elevated: #F0F1F3;
    --color-text-primary: #1A1D23;
    --color-text-secondary: #4A5568;
    --color-text-muted: #A0AEC0;
    --color-border: #E2E8F0;
    --color-border-subtle: #EDF2F7;
    --color-accent: #D6B65D;      // same gold or change per theme
    --color-accent-hover: #C9A84C;
    --color-accent-muted: #FEF9E7;
    --color-feedback-success: #38A169;
    --color-feedback-warning: #DD6B20;
    --color-feedback-error: #E53E3E;
  }

  [data-theme="blue"] {
    --color-accent: #3B82F6;      // replace gold with blue
    --color-accent-hover: #60A5FA;
    --color-accent-muted: #1E3A5F;
    // keep everything else
  }

Then set data-theme on <html> via a ThemeToggle component.

6. IMPORTANT NOTE ABOUT "DEAD" COLOR CLASSES
=============================================================================

Throughout the JSX, you'll see these classes that LOOK like theme colors:

  text-gold, bg-gold, bg-gold/5, bg-gold/10, bg-gold/20
  border-gold, border-gold/20, border-gold/30, border-gold/40, border-gold/50
  bg-navy, bg-navy-light, bg-navy-card, bg-navy-border
  border-navy, border-navy-border
  text-navy, from-navy-light, to-navy-card
  focus:ring-gold

NONE OF THESE CLASSES HAVE ANY CSS EFFECT. They are NOT defined in the
Tailwind config, NOT in tokens.css, and NOT in the compiled CSS output.
They are inert class names on HTML elements that do nothing.

The actual gold color comes from:
  - bg-accent / text-accent / border-accent (token system)
  - .btn-gold CSS component class (uses bg-accent)
  - hover:text-accent / hover:border-accent

For theme compatibility, you should eventually consolidate these dead
classes (replace text-gold -> text-accent, bg-navy-light -> bg-bg-elevated,
border-navy-border -> border-border, etc.). But the tokens.css theme system
will work regardless since the actual visuals are driven by the tokens.
